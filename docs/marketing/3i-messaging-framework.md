## Open questions to bring into the room

- Where do the two unassigned messages (Global Pathways, ITP) live on the home page without pushing it to a 9-section wall?
- Exact, legally-safe wording for the Harvard / KPMG / EFMD claims — confirm with partnerships/legal before this goes external.
- What does ITP stand for, and is there one approved description to use consistently across web, brochure, and social?
- Does "top company" in the ITP claim mean the same bar as "top companies" in Placement, so the two sections don't contradict each other?
- Should each pillar carry a consistent visual tag (icon/color/label) across sections so a visitor recognises which "I" a claim belongs to?
